ViMap

Archivo personal de notas y codigo

Esta aplicacion es un sitio estatico publicado en GitHub Pages. No sustituye un sistema de autenticacion con servidor: no almacenes secretos de produccion, credenciales, tokens ni informacion extremadamente sensible.

La boveda cifrada se descifra exclusivamente en tu memoria del navegador con una contrasena que nunca se guarda ni se transmite. Su seguridad depende de la fortaleza de esa contrasena.

Desbloquear boveda

Antes de usar el cifrado, entiende los limites de esta aplicacion:

  • Los archivos y manifiestos cifrados son descargables por cualquier visitante. Un atacante puede copiar el ciphertext y atacarlo por fuerza bruta offline.
  • El descifrado ocurre solo en tu navegador; GitHub Pages no ofrece backend ni autenticacion.
  • La seguridad depende de que uses una contrasena larga y aleatoria (o frase de paso de alta entropia). Si la olvidas, no hay recuperacion.
  • El limite de intentos fallidos es solo una ayuda de interfaz y no es una medida de seguridad real, puede eludirse con las herramientas del navegador.
  • No guardes aqui secretos de produccion ni datos que requieran control de acceso real.

La contrasena se usa solo para derivar la clave de descifrado en memoria. Se borra al bloquear o recargar. No se guarda ni se envia a ningun servicio.
